Placement: top, centred, 8 dp below the status-bar inset; 44 dp tall; surfaceVariant at 94 % alpha; 6 dp shadow. Never focusable, never touch-modal, so keyboards stay open and fullscreen apps stay fullscreen. After +10 s the pill disappears and stays away until 5 s, where it returns as State C — late, short and unmissable: the user has already had a warning and bought extra time, so the re-block is announced whether or not they tapped the first one away. Ignoring it, or reaching 0 s, leads to the unchanged re-intervention screen; the pill is removed just before it appears.
